# Mochi Diary 麻糬養成日記

一個可愛的習慣養成小網站：完成每日／每週任務讓麻糬變開心，累積連續天數和訓練時數，賺金幣在道具屋幫麻糬換裝。

## 功能
- 每日任務、每週任務（可設定一週幾次）
- 分次完成的任務，例如一天喝水 2500ml、每次 500ml
- 麻糬表情會隨完成度改變
- 連續活躍天數、里程碑獎勵、金幣
- 月曆與每日紀錄、累計小時數
- 道具屋：36 個道具，分頭頂、臉部、身邊、背景，可以同時穿戴
- 日間／夜間模式切換（抹茶色系）

## 使用
直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages。
紀錄存在瀏覽器的 localStorage，換裝置或清除瀏覽資料後不會保留。
